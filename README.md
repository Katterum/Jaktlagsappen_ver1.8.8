Jaktlaget 1.8.8 stabil basversion.

Förfiningar från 1.8.5:
- Startsidan växlar både registrerade djur och vuxenekvivalenter med valt djurslag.
- Fördelningsfärg: rött vid -5,0 procentenheter eller lägre, gult mellan -5 och 0, grönt från 0.
- Ny passöversikt med karta/lista, passbild, passhistorik och punktprognos.
- Passval via karta eller alfabetisk rullista.
- Passplacering sparas utan att lämna inställningssidan.
- Passtilldelning är ett nav för klassisk slumpning, kartval och guidad passrekommendation.
- Valda kartpass kan markeras/avmarkeras och slumpas mot medlemmar och gäster.
- Passförslag använder markerat jaktområde, upp till cirka 200 meter utanför, vind och tidigare observationer som beslutsstöd.
- Vindgrafik kan visas eller döljas för valda pass.

- Samma vindgrafik i passöversikt och passkarta som i jaktprognos.
- Mer återgår till tidigare scrollposition.
- Viltspår kan markeras som drivet av hund.
- Pass redigeras via rullista och kan arkiveras utan att historiken raderas.
- Defaultpass kan exporteras och importeras som JSON.
